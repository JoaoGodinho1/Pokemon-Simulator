You’ve probably wanted to run your own experiments with Pokémon—like figuring out which one is the best, or which one racks up the most wins over 500 battles—so I created this Pokémon simulator.
It’s not 100% complete; some moves have been rebalanced—for instance, instead of forcing the Pokémon to rest for a turn, *Giga Impact* now has a priority of -1 and deals reduced damage.
Status moves and abilities aren’t included yet; it’s still very basic, but it will continue to evolve.
The Pokédex is also far from finished—I plan to add all the different forms, such as Mega Evolutions, regional variants, and so on.
That’s about it! I hope you have fun using this beta version of my simulator. As it develops further, I’ll post the code here.
P.S. Feel free to critique the project and share your thoughts; I’m here to learn from those with more experience.
